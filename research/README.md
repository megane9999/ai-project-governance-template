## Rules

- 調査範囲、検索日または確認日、使用した主張、出典を記録する。
- 一次資料と承認済み内部正本を優先する。
- 第三者の主張は`確認済み外部事実`であり、自組織への適用は別に検討する。
- 数字は母数、期間、定義、単位がない場合に転用しない。
- 変わり得る情報はDecision直前に再確認する。
- 調査で決められない問いは、小さなExperimentまたは人間判断へ変換する。
- 古くなったResearchを黙って更新せず、変更履歴と判断への影響を記録する。
