# Initiative Registry

更新日: `<<YYYY-MM-DD>>`

Initiativeは、Charterへ寄与する成果単位です。細かなタスクや単発の調査はInitiativeにしません。

| ID | Initiative | State | Owner role | Intended outcome | Key uncertainty / blocker | Next action | Review |
|---|---|---|---|---|---|---|---|

## State policy

- `Inbox`: 未整理。
- `Researching`: 着手判断に必要な証拠を収集中。
- `Planned`: Scope、owner、完了条件が定義済み。
- `Active`: 作業中。
- `Blocked`: 明示した依存関係または判断待ち。
- `Parked`: 今は進めないが再検討条件がある。
- `Completed`: Intended outcomeと完了条件を満たした。
- `Cancelled`: 継続しない判断があり、Decisionと学習を保存済み。

## Rules

- Activeへ移す前に、成果、完了条件、主要Risk、次の検証を明示する。
- Blockedにはblocker、owner、解除条件または確認日を付ける。
- Completedは作業量ではなく、事前に定義した成果で判定する。
- Cancelled時は関連DecisionとArchiveへのリンクを残す。
- 台帳と個別ファイルを同じ変更で更新する。
