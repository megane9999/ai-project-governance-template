# Budget and Resource Ledger

## Principles

- 予算枠は支出承認ではありません。
- 予定額と実績額を別々に記録します。
- 現金以外の人間時間、他チーム工数、計算資源も独立した希少資源として扱います。
- 返金可能でも、支出時にactualを記録し、返金は別行にします。
- 通貨、税、為替、手数料、期間の仮定をnotesへ残します。
- AIは`approved_by_role`を自分で埋めません。

## Source of truth

`ledger.csv`をこのリポジトリ内の予定・実績支出の唯一の台帳とします。会社の正式な会計・調達システムが別にある場合、そのシステムが法的・会計上の正本であり、ここには参照IDとプロジェクト判断に必要な最小情報だけを置きます。

## Status

- `proposed`: 提案のみ。
- `approved`: 人間承認済み、未支出。
- `committed`: 発注・契約等で支払義務が発生。
- `paid`: 支出済み。
- `refunded`: 返金済み。返金は別行にも記録。
- `cancelled`: 未支出で取消。

## Additional investment gate

プロジェクトで定めた金額またはRisk閾値を超える場合、これまでの証拠、追加額、検証仮説、成功・失敗条件、最大損失、撤退条件、法務・セキュリティ影響をDecisionへ残します。
